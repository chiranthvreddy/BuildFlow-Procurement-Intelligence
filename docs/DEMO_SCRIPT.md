# Two-minute product walkthrough

1. **Command centre:** Explain separate KPIs for open overdue orders versus completed deliveries that arrived late. Point to the exception queue.
2. **Purchase orders:** Create a sample order. Explain the validation of quantity, dates and supplier fields. Update an open order status and add a note.
3. **Supplier comparison:** Choose a material and quantity. Discuss cost versus reliability and why these are indicative estimates rather than live quotations.
4. **Price intelligence:** Change the anomaly threshold. Explain the within-material median comparison and false positives.
5. **Product insights:** Describe the discovery hypotheses, proposed usability test, and what evidence would justify a production launch.

## Demo constraints
The workspace starts with deterministic synthetic data and a fixed 2026-10-22 demonstration date. Data changes are in-session only. There is no authenticated user or production backend.
